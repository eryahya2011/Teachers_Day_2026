# Teachers' Day 2026 — A Little Something

An interactive Teachers' Day experience made with plain HTML, CSS and JavaScript.

## Run
Open `index.html` in any modern browser. No VS Code or installation is required to view it.

## Personalization
The project is intentionally universal so the same link can be sent to school teachers, previous-school teachers, coaching teachers, etc.

Upload `index.html`, `style.css`, and `script.js` to a GitHub repository and enable GitHub Pages. Then share the resulting public link or convert it to a QR code.
